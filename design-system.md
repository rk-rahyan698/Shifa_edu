# Shifa International School — Website Design System

**Version 1.0** | Prepared for website redesign & future social media use

---

## 1. Design Philosophy

The current logo and uniforms are bright, playful, and color-heavy (kelly green, black, yellow, teal). That works well for a physical sign or a badge, but a full website built entirely in bright green and yellow reads as loud, dated, and hard to read for long stretches of text — not the tone a private international school wants for admissions, academics, and parent communication.

This system keeps the **brand's DNA** (green identity, gold/yellow highlight, the teal from the uniform) but translates it into **deeper, muted, formal tones**, set against a **white/cream base**. The result should feel: trustworthy, academic, calm, and premium — closer to the international school references researched below (Benjamin Franklin International School, Singapore American School, Sevenoaks) than to a nursery or daycare site. Those sites succeed through clean layouts, generous white space, confident typography, and restrained color used as accent rather than background — that is the model this palette follows.

## 2. Color Palette

### 2.1 Base / Background Colors
These dominate the site — roughly 70–80% of any page.

| Name | Hex | Usage |
|---|---|---|
| **Pure White** | `#FFFFFF` | Primary page background, content cards |
| **Warm Cream** | `#FAF7F0` | Alternate section background (softer than pure white, echoes uniform khaki without being tan) |
| **Off-White Border** | `#EDE9DD` | Dividers, card borders, subtle section separation |

### 2.2 Primary Brand Color
| Name | Hex | Usage |
|---|---|---|
| **Deep Forest Green** | `#1E4B3A` | Logo-derived primary. Header/nav bar, footer, primary buttons, section headings, active states |
| **Forest Green — Hover/Light** | `#2E6B52` | Hover states, secondary emphasis, icons |

This is a deepened, desaturated version of the logo's kelly green — professional rather than playful, but instantly traceable back to the school's identity.

### 2.3 Secondary / Text Color
| Name | Hex | Usage |
|---|---|---|
| **Charcoal Ink** | `#22262A` | Body text, headings on white (replaces pure black from the logo's black ring — softer, more readable) |
| **Slate Gray** | `#5B6470` | Secondary text, captions, metadata (dates, labels) |

### 2.4 Accent Color
| Name | Hex | Usage |
|---|---|---|
| **Muted Gold** | `#B8912F` | Small accents only: underlines, icons, "Apply Now" highlight, awards/badges. A formal, muted descendant of the logo's bright yellow lettering |
| **Gold — Light Tint** | `#F1E4C2` | Very light background tint for callout boxes, quote blocks |

### 2.5 Supporting Accent (from Uniform)
| Name | Hex | Usage |
|---|---|---|
| **Uniform Teal** | `#3A7A72` | Links, secondary buttons, tags/badges — bridges the green and neutral tones, used sparingly |
| **Uniform Khaki** | `#DCCFA8` | Optional textured section backgrounds (e.g. "Campus Life" section), used in small doses only |

### 2.6 Functional Colors
| Name | Hex | Usage |
|---|---|---|
| **Success Green** | `#3E8E5A` | Form confirmations, success states |
| **Alert Red** | `#B3413A` | Errors, required-field warnings (muted brick red, not the loud red common in school sites) |

### Color Ratio Guideline (60-30-10 rule)
- **60%** — White / Cream backgrounds
- **30%** — Deep Forest Green (nav, footer, headings, buttons)
- **10%** — Gold + Teal accents (CTAs, links, highlights)

Avoid ever pairing bright green + bright yellow together at full saturation on the website — that combination should live only in the physical logo mark itself.

## 3. Typography

International school sites researched (Benjamin Franklin International School, Singapore American School, Sevenoaks, Gordonstoun) lean on confident serif or refined sans-serif headings paired with a clean, highly legible sans-serif body — never playful/rounded fonts, which read as primary/daycare rather than K–12 academic.

### 3.1 Heading Font — Formal Serif
**Primary: "Playfair Display"** (or "Lora" / "Merriweather" as alternates)
- Used for: page titles, section headings, pull quotes
- Weight: 600–700 (Semibold/Bold)
- Conveys: tradition, academic credibility, established institution

### 3.2 Body Font — Clean Formal Sans-Serif
**Primary: "Source Sans 3"** (or "Inter" / "Nunito Sans" as alternates)
- Used for: paragraphs, navigation, buttons, forms, captions
- Weight: 400 (regular), 600 (semibold for emphasis)
- Conveys: clarity, modern professionalism, easy readability on all devices

### 3.3 Type Scale (Desktop)
| Element | Font | Size | Weight | Color |
|---|---|---|---|---|
| H1 (Hero) | Playfair Display | 48–56px | 700 | Charcoal / White (on green) |
| H2 (Section) | Playfair Display | 32–36px | 600 | Deep Forest Green |
| H3 (Subsection) | Playfair Display | 22–24px | 600 | Charcoal Ink |
| Body | Source Sans 3 | 16–18px | 400 | Charcoal Ink |
| Small / Caption | Source Sans 3 | 13–14px | 400 | Slate Gray |
| Button / Nav | Source Sans 3 | 15–16px | 600 | varies |

Mobile scale: reduce H1 to 32–36px, H2 to 26px, body stays 16px for readability.

## 4. Logo Usage

- Maintain clear space around the logo equal to the height of the "S" in the emblem.
- On white/cream backgrounds: use full-color logo as-is.
- On dark green backgrounds (e.g. footer): use a white/reversed version of the wordmark.
- Never recolor the logo itself to match site tones — it stays as the official mark; the *website* adapts to it, not the reverse.
- Minimum digital size: 60px height (favicon uses the "SIS" emblem only, simplified).

---

## 5. Components

### Buttons
- **Primary button:** Deep Forest Green background, white text, gold underline/border on hover, 6–8px rounded corners
- **Secondary button:** White/transparent background, Forest Green border and text, fills green on hover
- **Text link:** Uniform Teal, underline on hover

### Navigation Bar
- White or cream background, Charcoal Ink text, Forest Green for active/current page
- Sticky on scroll, with a thin gold bottom border (1–2px) as a subtle signature detail

### Cards (Programs, News, Staff)
- White background, `#EDE9DD` border or soft shadow
- Gold or teal thin accent bar at the top of the card
- Rounded corners (8–12px), generous padding

### Footer
- Deep Forest Green background, white/cream text, gold accent for links on hover
- Uniform Khaki used only as a subtle texture/pattern (very low opacity) if desired — never solid

### Forms (Admissions/Contact)
- White background, Charcoal labels, Forest Green focus outline
- Primary CTA button in Gold to draw attention to submission (only element allowed in full-saturation gold)

---

## 6. Imagery & Photography Style

- Prefer natural, warm-toned photography of real students/campus over stock graphics or cartoon illustration (cartoon/mascot style reads younger than the school's full K–9+ range).
- Apply a very subtle warm filter to photos so they harmonize with the cream background rather than clashing with cool blue/teal building glass.
- Use the Forest Green or Gold as duotone overlay only on hero banners if needed for text legibility — never as a full-image color filter elsewhere.

---

## 7. Iconography

- Simple, thin-line icons (1.5–2px stroke), Forest Green or Charcoal by default, Gold or Teal only for hover/active states.
- Avoid filled, cartoon-style, or multi-color icon sets — keep icons monochrome per instance for a formal look.

---

## 8. Social Media Adaptation Notes (for future use)

When this palette is later extended to social media:
- **Profile/cover images:** Deep Forest Green + White/Cream, logo centered, gold accent line
- **Post templates:** White or cream base card, Forest Green header bar, Gold used only for a small tag/label ("Admissions Open", "Event")
- **Quote/announcement graphics:** Cream background, Charcoal serif heading, thin gold rule beneath
- **Story highlights icons:** Line icons in Forest Green on a cream circle
- Keep the bright/full-saturation green + yellow combination (as in the current logo lockup) reserved for the **logo watermark only**, not backgrounds — this keeps social content visually consistent with the new, calmer website.

---

## 9. Accessibility

- Charcoal Ink (`#22262A`) on White (`#FFFFFF`) — contrast ratio ~15.8:1 (AAA)
- White text on Deep Forest Green (`#1E4B3A`) — contrast ratio ~8.4:1 (AAA)
- Gold (`#B8912F`) on White — ~3.3:1 — use only for large text (18px+/bold) or icons, not small body copy
- Always pair color with an icon, underline, or label for critical actions/errors — never rely on color alone
